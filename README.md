# 四级冲刺 · CET-4 Sprint

面向大学英语四级（CET-4）的本地学习复习网站。一期版本聚焦三件事：**把单词按记忆规律背完、把阅读听力和翻译练透、把错题收干净**。

纯静态站点，无需安装依赖、无需后端，双击 `start.cmd` 即可使用，学习记录保存在浏览器本地。

![首页](preview/home.png)

---

## 快速开始

**方式一（推荐）**：双击 `start.cmd`，脚本会用 Python 起一个本地服务并打开 <http://127.0.0.1:5178/>。关闭命令行窗口即停止。

**方式二**：直接双击 `index.html`。部分浏览器在 `file://` 下会禁用 `localStorage`，页面顶部会出现「临时模式」提示，数据不会保存。

> 建议用 Edge / Chrome 打开。听力朗读依赖系统语音合成（Windows 自带英文语音即可）。

## 已实现功能（一期）

### 1. 抽查单词 · 费曼式回忆
- 内置 **1500 个四级核心词**（后 500 个来自 ECDICT），支持搜索词形与释义
- 每天默认 **50 个**，10 个一组；随时点「+10 个」加量（上限 200）
- **完全随机抽词**：不按字母顺序，每次进入抽查都会重新洗牌
- 流程：看词 → 自己复述释义 → 翻面 → 自评「忘记 / 模糊 / 认识 / 简单」四档，间隔按评级自动调整
- 释义卡：多义项 + 例句 + 记忆提示，标注「释义综合参考牛津 / 朗文 / 柯林斯」
- 键盘：`1–4` 评分，`空格` 朗读单词，`Ctrl/Cmd+Z` 撤销上一题；每组结束可休息
- 答错自动进入错词本，次日回到抽查队列

### 2. 单词本
- 抽查时遇到不熟的词，点卡片上的「加入单词本」即可收藏；**答错的词会自动进本**
- 单词本有独立入口（侧边栏 / 手机顶栏书签按钮 / 抽查页顶部卡片）
- 单词本里的词点一下即可看完整释义、例句、记忆提示和真题语境；详情里可直接移出单词本
- 支持按费曼法单独复习：看词 → 复述 → 翻面 → 自评「忘了 / 模糊 / 记得」，进度独立，不占每日 50 个抽查名额
- 可在单词本里逐条移出或一键清空，不影响原抽查进度

### 3. 阅读 · 三种题型
- **仔细阅读**：2 套，每套 5 题，交卷后**定位句高亮** + 逐题解析
- **长篇匹配**：1 套，12 段（A–L）配 10 个陈述句，交卷后点题号可跳到对应段落
- **选词填空**：2 套，每套 10 空 + 15 个备选词；点空格再点单词，交卷后逐空给解析
- 三种题型都支持计时、重做，答错的题自动进入错题本
- **点词查义**：点击文中任意单词弹出释义（词库词显示音标/词性/义项/例句，可朗读）；词库内按频段着色：高频红、中频黄、低频与库外绿

### 4. 听力 · 长对话 / 篇章
- 2 套原创听力材料，由浏览器语音合成朗读，支持 0.85× / 1× 变速
- 可显示原文并**逐句播放**（精听）
- 交卷后给出答案、解析与原文出处

### 5. 翻译 · 逐句汉译英
- 4 段原创模拟题：春节、剪纸、移动支付、数字故宫（传统文化 + 数字生活）
- **一次一句**：中文句 → 输入译文 → 对照参考译文与提示 → 下一句；可回看上一句
- 草稿自动保存，底部圆点显示每句进度
- 全段完成后：**得分点自动检查**、逐句对照（你的译文 + 参考译文）、自评档位（13–15 … 1–3）

### 6. 错题本 / 首页 / 设置
- **错词 / 错题 / 自定义** 三个页签：前两个自动收集，自定义可手动添加、删除（单词、题号、知识点都行）
- **错题按大题聚合**：一个 Passage 只占一条，红色数字标出做错的小题；点数字直接跳到原文对应定位句，点「查看整题」进入整篇回顾
- 回顾页：文章定位句前标小题号（错题标红），错题卡片红框、正确答案高亮、解析直接展开，可一键重做整篇
- 外观：跟随系统 / 浅色 / 深色，深色模式覆盖全部页面并记住选择
- 单词库里点任意词条，弹出完整释义卡：音标、词性、多义项、例句、记忆提示、**真题语境例句**，可一键加入自定义错题本
- 首页：考试倒计时、备考进度环、连续打卡、今日计划（抽查/阅读/听力/翻译）、12 周学习热力图
- 设置：考试日期、每日新词量、复习上限、昵称、数据导出/导入/清空

### 7. 真题导入（PDF → 题库）
- 把解析版 PDF 放进 `import/`，三步生成题库：抽文本 → 结构化 → 生成 JS
- 自动识别年份 / 月份 / 套数 / 题型，题目标题与错题都带来源（如 `2026年6月·第1套`）
- 已导入 9 套（2025-06 三套、2025-12 三套、2026-06 三套）：仔细阅读 18 篇、长篇匹配 9 篇、选词填空 9 篇、翻译 9 段、写作 9 题（写作 UI 待接）
- 合并时按正文指纹去重，重复的套题/文章不会重复入库；全部套卷打进 `bundle.js`，页面只加载一个文件
- 局限：只支持文字版 PDF；听力只有题目没有音频，暂不导入

```bash
python tools/pdf_extract.py import/xxx.pdf import/xxx.txt
python tools/parse_paper.py import/xxx.txt assets/js/data/papers/xxx.json 2026 6 1
python tools/json_to_js.py assets/js/data/papers/xxx.json assets/js/data/papers/xxx.js
# 再把 xxx.js 加进 index.html 的 data 脚本区
```

### 8. 离线词典（ECDICT）
- 内置 ECDICT 精简版：58,013 词条，按首字母拆成 26 个分片，共 4.9MB，查某字母时按需加载
- 阅读点词、词库搜索都能查任意单词；完全离线，`file://` 打开也能用
- 词库里的 1500 个词优先显示精修释义，其余词自动走 ECDICT
- 数据来源 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT），构建脚本 `tools/build_dict.py`

```bash
# 重新生成词典分片（需要先下载 ecdict.csv 到 import/）
python tools/build_dict.py
```

### 9. 在其他设备使用
**线上地址（GitHub Pages）**：https://ddddddlt.github.io/cet4-sprint/

| 方式 | 适用场景 | 做法 |
|---|---|---|
| 单文件 | 手机 / U 盘 / 另一台电脑，完全离线 | `python tools/build_standalone.py` 生成 `cet4-sprint-standalone.html`（约 6.6MB，含词典），拷过去双击打开 |
| 局域网 | 同一 Wi-Fi 的手机 / 平板 | 电脑运行 `start-lan.cmd`，手机浏览器打开提示的 `http://电脑IP:5178/` |
| 公网临时链接 | iPhone / 任何有网设备 | 电脑运行 `start-public.cmd`，日志里出现 `https://xxxx.trycloudflare.com` 就是地址（每次启动会变，电脑需开机） |
| 静态托管 | 随时随地有网 | 整个目录传到 GitHub Pages / Cloudflare Pages / Netlify 即可 |

- 学习记录存在浏览器 `localStorage`，**按设备独立**；换设备用 设置 → 导出学习数据 / 导入数据 迁移
- iPhone 的 Safari 不方便直接打开本地 HTML，建议走局域网或静态托管
- 单文件版在更新题库/词典后需要重新生成；网页版不受影响

### 10. 多设备同步（可选）
- 设置 → 云同步：粘贴 GitHub Token（`public_repo`）并保存
- 默认开启「自动上传」：记录变化约 6 秒后自动上传；切后台/关页面立即上传；失败 60 秒后重试
- 也可以手动「上传本机进度 / 下载云端进度」；两台设备共用同一个仓库文件
- 注意：进度文件在公开仓库里（只读公开）；Token 只存在本机浏览器，不会随导出文件带走

## 数据说明

### 11. 写作（真题作文）
- 9 套真题作文，题干从原卷 PDF 重新抽取（完整 Directions）
- 写作页：30 分钟计时、120–180 词输入、实时词数、草稿自动保存
- 完成后展示参考范文 + 中文译文，可重写；记录随导出/云同步保存

### 词库字段

```js
{
  id: 'w001',                          // 唯一标识，学习进度靠它关联，不要重复
  w: 'abandon',                        // 单词
  ph: '/əˈbændən/',                    // 音标
  pos: 'v.',                           // 词性
  zh: '放弃；抛弃；遗弃',                // 释义（会作为选项展示，建议 2–4 个义项）
  ex: 'He had to abandon his plan...',  // 例句（可选）
  exZh: '因为费用问题，他不得不……',       // 例句翻译（可选）
  note: 'a- + band + -on：解开束缚'      // 记忆提示（可选）
}
```

扩充方式：直接编辑 `assets/js/data/words-core.js`，在数组里追加词条即可（`id` 保持唯一，新词会按字母自动排序）。目前 1500 词中有 120 个带例句与翻译，其余只有音标和释义。

### 题库字段

```js
{
  id: 'r1', title: 'The Attention Trade', type: '仔细阅读',
  minutes: 8, intro: '数字生活 · 注意力经济',
  passage: `第一段\n\n第二段`,           // 用空行分段
  questions: [{
    id: 'r1q1', stem: '题干', options: ['A','B','C','D'],
    answer: 1,                            // 正确项下标 0–3
    evidence: '原文片段',                  // 必须是 passage 中的原文，用于高亮定位句
    explain: '解析文字'
  }]
}
```

听力结构相同，字段为 `transcript`（段落用空行分隔，`M:` / `W:` 开头会被识别为说话人）与 `seconds`。

### 选词填空 / 长篇匹配字段

```js
// 选词填空
{
  id: 'c1', type: '选词填空', title: '...', minutes: 10,
  passage: '正文，用 {{1}} 到 {{10}} 标记空格',
  bank: [{ k: 'A', w: 'adjust', pos: 'v.' }, /* ... 共 15 个 */],
  blanks: [{ no: 1, answer: 'D', explain: '解析' }]
}

// 长篇匹配
{
  id: 'm1', type: '长篇匹配', minutes: 15,
  paragraphs: [{ k: 'A', text: '段落正文' }, /* ... */],
  statements: [{ id: 'm1s1', text: '陈述句', answer: 'E', explain: '解析' }]
}
```

选词填空的 `answer` 是备选词字母；长篇匹配的 `answer` 是段落字母，两句都写进同一文件 `reading-extra.js` 即可。

### 翻译字段

```js
{
  id: 't1', title: '春节', topic: '传统节日', level: '中等', minutes: 15,
  zh: '春节是中国最重要的传统节日……',        // 全文，用于展示与字数统计
  sentences: [{
    zh: '春节是中国最重要的传统节日，通常在农历正月初一庆祝。',
    en: 'The Spring Festival is ...',       // 参考译文
    tip: '「农历正月初一」可译为 ...'        // 翻译提示（可选）
  }],
  keyPoints: [{                              // 得分点：命中任一英文表达即算译出
    zh: '春节', en: ['the Spring Festival', 'Spring Festival', 'Chinese New Year']
  }]
}
```

得分点匹配会忽略大小写，并把中文引号统一为英文引号；多写同义表达（如 `paper cutting` / `paper-cutting`）能提高命中率。

### 本地存储

键名 `cet4-sprint/v1`，结构：
```js
{
  version, createdAt,
  settings: { examDate, newPerDay, reviewCap, name },
  cards: { [wordId]: { S, D, due, reps, lapses, last, lastGrade, wrong } },
  daily: { '2026-11-09': { reviews, correct, newWords, reading, listening, translation, seconds } },
  attempts: { reading: {...}, listening: {...}, translation: { [setId]: { score, total, best, times, graded } } },
  wrong: { words: {...}, questions: {...} },
  drafts: { translation: { [setId]: '未提交的译文' } }
}
```

设置页可导出为 JSON 备份，换设备时导入即可。

## 间隔重复规则（简化 FSRS）

| 评级 | 触发条件 | 稳定度变化 | 下次间隔 |
|---|---|---|---|
| 1 忘记 | 答错 | S × 0.3（首次 0.4） | 明天（本轮再出现一次） |
| 2 模糊 | — | S × 1.25 | 约 S 天 |
| 3 认识 | 答对但超过 3.8 秒 | S × 2.1 | 约 S 天 |
| 4 简单 | 3.8 秒内答对 | S × 3.2 | 约 S 天 |

难度 `D` 随评级升降并钳制在 1–10，避免难词一直被排到很远的将来。稳定度 `S ≥ 21` 记为「已掌握」。

## 已知限制

- **内容为原创模拟题，不是历年真题**：真题版权归考试院，公开传播有风险；如需真题，建议仅个人使用并注明来源。
- 听力音频来自浏览器语音合成，音色取决于系统语音包，正式备考建议配真题音频精听。
- 无账号体系，数据只在本机浏览器；换浏览器/清缓存会丢失（可导出备份）。
- 1500 词中只有 120 个带例句，其余词不会出现「例句填空」题型。
- **翻译不是机器评分**：系统只做「得分点覆盖 + 逐句参考对照」，最终分数由你自评；接入 LLM 后才能做真正的批改。
